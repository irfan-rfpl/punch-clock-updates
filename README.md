# Punch Clock — updates

This repo holds only build output, never source code:

- OTA manifest + bundles for [Capgo](https://github.com/Cap-go/capacitor-updater) live updates, served via GitHub Pages, consumed automatically by the app on launch.
- APK releases for native-level changes, consumed via [Obtainium](https://github.com/ImperiumLabs/Obtainium).

Source lives in the private `punch-clock` repo.
